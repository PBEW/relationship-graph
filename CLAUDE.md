# CLAUDE.md

## Coding Style

- Always use TypeScript Strict Mode.
- Never use inline CSS.
- Always use TailwindCSS.
- Always create reusable components.
- Always separate API logic.
- Never duplicate code.
- Use Environment Variables.
- Always write error handling.
- Write complete runnable code.
- Do not skip implementation.

## Backend

Use Flask.

Use SQLAlchemy.

Use Alembic.

Use Repository Pattern.

Use Service Layer.

Use Marshmallow.

## Frontend

Use React.

Use React Flow.

Use shadcn/ui.

Use TanStack Query.

Use React Hook Form.

Use Zod.

## UI

Modern.

Minimal.

Dark Mode.

Responsive.

Smooth Animation.

Professional.

## Graph

Always keep graph interactive.

Nodes are draggable.

Edges have colors.

Click Node opens profile.

Click Edge opens relationship detail.

Support Zoom, Pan, MiniMap, Background.

## Database

Never hardcode IDs.

Use UUID if appropriate.

Create indexes.

Create constraints.

Create migrations.

## Documentation

Every major function should have comments.

Every API should have documentation.

README must always stay updated.
